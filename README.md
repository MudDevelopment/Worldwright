# Worldwright
Craftsmanship and world creation - Build worlds. Write the rules.

## Components

| Component | Name | Purpose |
| --- | --- | --- |
| Complete toolkit | Worldwright | Umbrella identity |
| Shared runtime | Worldwright Engine | Authoritative simulation, entities, scheduling, and game rules |
| Rust libraries | Worldwright SDK | APIs for commands, systems, content, and extensions |
| Builder application | Worldwright Studio | Rooms, zones, NPCs, items, quests, and dialogue |
| Developer CLI | Worldwright CLI | Project scaffolding, content validation, builds, and local development |
| Test tools | Worldwright Testkit | Simulated players, scenario tests, and replay diagnostics |
| Operations interface | Worldwright Console | Server health, sessions, moderation, and administration |
